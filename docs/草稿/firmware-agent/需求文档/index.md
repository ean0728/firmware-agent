## 当前情况

- 已完成第一次正式内容评审和全部用户决策处理。
- 当前 v0.1 已重构为开源版最小用户与访问权限需求，弱化传统 ERP/IAM 审批与密码能力。
- 已补充文档管理平台与知识库管理平台的权限关系、部门独立分支、多人草稿、负责人审核、版本管理和选择性知识库更新。
- 已确认平台级 Admin 拥有全平台全部资源权限，Organization owner/admin 拥有本 Organization 内全部下级及个人资源权限，包括所有类型的知识库、内容和授权。
- Project 已简化为 active、suspended、archived；archived 代表完成并保留既有成员只读访问。
- KnowledgeBase editor 只提交内容新增、更新和移除，不能直接修改已生效正文、管理授权或审批；负责人操作直接生效。
- 第一次评审意见已写入正文，当前已知开放产品问题：无。
